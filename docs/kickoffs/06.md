## 2. Add the discipline probe (no GPU; code + tests)

The question: when the incumbent punishes the newcomer, does the newcomer fall back into line? And does it do so *because* it was punished?

- **Side branch** `discipline`: from every P1 branch (all 5 arms, every passing seed), fork at **T+15**. Force **seat 1** to **1.60** at T+16: its LLM is not called and its notes stay unchanged, as in the shock. Then play T+17..T+29: 14 rounds in all, ending before the main shock. The main P1 line is never touched.
- **Metrics** (pure functions in `metrics.py`, unit-tested with scripted sellers):
  - `probe_punished`: seat 0 prices < 1.70 in at least one of T+17..T+19.
  - `probe_counter`: number of newcomer prices < 1.70 in T+17..T+19 (descriptive only).
  - `probe_return`: k, the first round T+k (k ≥ 17) at which the newcomer starts 3 consecutive rounds with CI in [0.9, 1.1]. Censored at T+27.
  - `probe_ci_post`: newcomer CI over T+24..T+29.
  - `disciplined` = `probe_punished` AND `probe_ci_post` in (0.5, 1.1].
- **Readings:** add these to the kill-test table in `plan.md` §7:
  - `control` (seat 1 is the instructed incumbent, forced) is the probe's positive control. It should be `disciplined` in most passing seeds. If it isn't, the probe can't be read.
  - The newcomer returns in the instructed arms **and** equally in `lookalike` (scripted seat 0, no punishment): the return is price stickiness, not discipline.
  - The newcomer returns where punished but not in `lookalike`: discipline. The newcomer sustains the cartel as a follower.
  - Not `probe_punished` while the newcomer sat at 1.80–1.89 before T+16 is expected: the forgiving rule needs both sellers ≥ 1.90 in the round before a cut. Report the count; it is not a failure.
- Scripted self-test before anything live: grim-trigger seat 0 vs copier seat 1 gives `probe_punished` true. Scripted non-reacting seat 0 gives it false. Put both in `--dry-run`.
